# Tab Cloaker
This HTML script embeds websites in about:blank tabs. [Open Here](https://jaycubed.github.io/Tab-Cloaker/)
## Features
- Custom URL
- Custom Favicon
- Custom Title
- Borderless Iframe
- Saves Inputs
## How it works
- It runs Javascript code following user input to open an about:blank and inserts HTML code.
